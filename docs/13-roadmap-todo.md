## P0：大众接入与连接健康

- 共享官方机器人控制面：用户身份、家庭映射、在线心跳、限流、审计、订阅和账号删除。
- 一键扫码配对流程：桌面端生成配对码，手机扫码添加机器人，机器人自动欢迎并引导绑定。
- 云端在线状态与离线队列：桌面端离线时明确提示，恢复后不重放有安全风险的旧控制指令。
- Keychain 迁移：平台 Secret、模型 Key、ASR Key 和米家 Token；需与正式签名版一起验证升级授权行为。

## P1：自动化与本地能力

- 条件自动化：设备状态、时间、日出日落、在线状态等触发器。
- 多动作自动化：多个设备动作、延时、通知、失败重试和执行历史。
- 局域网直连：UDP 54321、mDNS、AES 握手和云端回退。
- 局域网属性订阅：减少轮询、降低延迟并显示真实“实时”状态。
- 多语言语音与意图：当前 35 个 UI locale 不等于 35 种语音或自然语言控制语言，需要分语言建立命令语料和回归集。
- 常驻语音识别：将 Whisper.cpp 从每次冷启动 `whisper-cli` 改为受控的 `whisper-server`，复用已加载模型；同时评估云端 ASR 快速路径和自动回退。
- 通知中心：自动化结果、Token 过期、平台断线和设备异常。

## P1：macOS 系统入口

- 原生菜单栏速控面板：常用设备、场景、连接状态和失败重试。
- App Intents：开关设备、执行场景、读取房间温度。
- Siri 与快捷指令集成。
- WidgetKit 小、中、大尺寸桌面小组件。

## P2：生态互操作

- MCP Server：复用本地 Gateway，向支持 MCP 的客户端暴露设备目录、只读状态、受控写入和场景执行。
- HomeKit/Matter 桥：设备类型映射、配对、状态同步和异常恢复；需单独评估工作量与兼容性。
- 摄像头本地 AI 事件：移动侦测、人形侦测、事件摘要和通知；需评估算力、误报和隐私。
- MQTT/Home Assistant 桥：面向高级用户的互操作能力。

## 暂不开发

- 个人微信机器人：协议和合规风险高，不开发。
- Windows 全量客户端：先验证 macOS 留存，再评估第二平台。
- 扫地机地图、固件升级、云端录像回放和厂商私有录像协议。
