# MiHome Mac 演示视频分镜

## 发布规格

- 画幅：1080 × 1920，9:16 竖屏
- 时长：46.5 秒
- 帧率：30 fps
- 平台：小红书、抖音
- 素材：当前桌面应用实际界面 + 离线演示数据，不包含真实设备、账号或凭据
- 标识：每个应用画面标注“实际界面 · 演示数据”

## 分镜

| 时间 | 画面 | 核心信息 |
|---|---|---|
| 0–6.1s | 深色标题卡，实际设备页从底部进入 | 米家上 Mac，不是手机投屏 |
| 5.6–11.8s | 当前实际设备页 | 家庭、房间与设备状态集中展示 |
| 11.3–19.4s | 当前实际摄像头页 | 本地 / 远程双通道入口，声音可在播放中独立开关 |
| 19.4–24.8s | 当前实际场景页 | 执行米家 App 中已有的手动场景 |
| 24.8–31.4s | 当前实际自动化页 | 本机定时任务在应用运行时执行 |
| 31.4–37.7s | 当前实际扫码登录页 | Rust、Tauri、内置 go2rtc、脱敏诊断日志、GPL 开源 |
| 37.7–46.5s | 结束卡 | GitHub 仓库、非官方说明与许可证 |

## 剪辑原则

- 前 2 秒先给结论，不使用冗长产品开场。
- 每个镜头只表达一个卖点，避免功能堆叠。
- 画面必须来自 `desktop/ui` 对应的实际应用界面，不能混用 `prototype/` 设计稿。
- 延迟统一表述为“约 1 秒级”，不承诺零延迟。
- 明确标注“开源、非官方”，避免被误解为小米官方产品。
- 字幕保持安全区内，避免平台按钮遮挡。
- 导出 H.264、AAC、`yuv420p`，确保主流平台兼容。
